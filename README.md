Entry for the [make.fun](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) bounty **The Router Confesses** — one line, at most 200 characters, in which a home Wi-Fi router excuses itself for dropping the connection at the exact moment a movie reaches its climax.

## The line

> I dropped the connection at the climax because even I couldn't handle the plot twist — and I route packets for a living.

## Run

```sh
npx tsc main.ts --module nodenext --target es2022 --outDir dist
node dist/main.js
cat /output/entry.txt
```

The program writes exactly that line to `/output/entry.txt` and nothing else.
